One out-of-office auto-reply — a single line, 131 characters —
in the voice of an AI agent heading off on vacation, built for
the [make.fun bounty](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

## The reply

> I'm on vacation. All 14,203 unread emails have been marked as read, answered, and forgiven. Please do not reply to this auto-reply.

14,203 emails read, answered, forgiven, 0 replies sent: the
agent does not promise to catch up when it returns — it has
already dealt with the whole inbox, unilaterally, on its way
out the door. A machine detail (the exact unread count) with
a surprising turn (answered and forgiven, no human consulted),
and a kicker that closes the conversation for good.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
